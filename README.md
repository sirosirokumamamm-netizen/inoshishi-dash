# LASER SLICER / FLOW

ブラウザ向けの自由軌跡・物理切断ゲーム。色合わせ版から、実際に多角形を切断するオリジナルの操作へ戻しました。

## 現在のルール

- 指／マウスで物体を横切るようになぞると、その場で切断。スワイプ方向を画面外へ延長せず、動かした軌跡の近くの物体だけを対象にします。
- 同じ物体を同一ジェスチャーで繰り返し分割しません。分割された断片はMatter.jsで回転・落下し、次のスワイプで再切断できます。
- 通常は元の物体面積の32%以下の断片が光になって消えます。切断自体にも点数がありますが、消去すると高得点です。
- 指を置いて動かしている間は物理時間が18%に。制限時間は通常速度で進みます。
- 2.2秒以内の連続切断でコンボが増加。消去目標達成で次のシークエンスへ進み、残り時間＋3秒。初期は60秒、上限65秒。
- 物体は定期的に下から浮上。赤いリングは切ると−3秒。切り残した物体が画面下などへ落ちると−1秒。消去済みの演出断片にはペナルティがありません。
- 切断・消去でチャージ。満タンのOVERDRIVEボタンで8秒間、消去閾値と得点が2倍になり、物理時間が70%に（照準中は18%）。
- 一時停止・非表示タブでは時間と物理を停止。Escでも切替。最高点はlocalStorage保存。
- 「調整」から音と演出（揺れ・粒子・対応端末の振動）を切り替えられます。初期状態はOSの視差効果軽減設定を尊重します。

## 開発と検証

Node.js 22.12以降（本環境24.19）。

```sh
npm ci --cache /tmp/laser-npm-cache
npm run dev
npm test
npm run test:e2e
npm run build
node tests/pages-smoke.mjs
```

`src/main.js`：切断と入力、Matter.js、状態遷移、Canvas、音。`src/geometry.js`：多角形分割・面積・重心。`src/style.css`：レスポンシブUI。旧ステージ・色合わせルールとテストは比較用に残していますが現在のゲームからは使用しません。

E2Eは実際の切断による得点、再切断による消去、オーバードライブ、一時停止、設定、モバイル幅、時間終了と再挑戦を確認します。システムChromiumがない他環境では `npx playwright install chromium` が必要です。

実機Safari／Androidでの操作感と性能、得点バランス、長く遊びたくなるかは未検証です。自動テストの成功を面白さの証明とは扱いません。広告・課金・外部データ送信はありません。
