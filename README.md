# LASER SLICER / CASCADE

切る場所で結果が変わる物理パズル。自由切断版FLOWを、支点・足場・受け皿・共鳴コアを持つ3つの構造パズルへ拡張しました。

## ゲームの因果関係

1. 金色のケーブルはMatter.jsのConstraintとして鋼の足場を吊っています。
2. 片側だけ切ると残した支点を中心に足場が傾きます。両側を切ると落下します。
3. 上に積まれた結晶が実際の接触・摩擦・重力で滑り落ちます。
4. 緑の受け皿に入った面積を回収。紫のコアは衝突・回収で起動し、周囲112単位の結晶を消去、他のコアへ0.14秒遅れて伝播し、外側の物体を物理的に押します。
5. 初期結晶総面積の80%以上を回収／消去するとクリア。達成後も0.8秒間は崩れの回収を継続し、得点と評価に反映します。

## 操作とルール

- ドラッグして直線を照準、離すと1ショット。画面外へ延長せず、その線が横切る対象だけを切断します。
- 照準中は物理演算を停止。光るケーブルが対象で、支点が外れる方向を文字で表示します。物理軌道の完全な予報ではありません。
- 空振りも1ショット。20フィールド単位未満の操作・キャンセルは消費なし。
- 発射後は崩れが落ち着くまで次の切断を待ちます（最低0.8秒、最大6秒）。最後のショットでも、その崩れを計算してから失敗を判定します。
- 結晶自体も切断可能。元面積450以下の小片は直接消去。分割前後の面積を保存します。鋼の足場と紫コアは切れません。
- 赤い範囲へ落ちた結晶は消失し、得点になりません。残る全結晶を回収しても80%に届かない場合は失敗。
- 無制限の連打や生存時間ではなく、ステージごとの2〜3ショットで攻略します。制限時間はありません。
- 回収スコアは初期面積比×10,000点。1.5秒以内の連続回収で最大10段階まで12%ずつ連鎖倍率を追加。切断だけでは加点しません。クリア時、残りショット×1,500点。
- 95%以上かつ残り1ショット以上で★3、80%以上かつ残り1ショット以上で★2、残り0で★1。最高点と最高評価を別々に保存。
- ポーズ／設定／非表示タブでは物理を停止。ステージはいつでも選択でき、やり直せます。

## ステージ

- **支えを外す**：2本のケーブル、広い受け皿。崩壊とまとめ回収を知る導入。
- **残す支点**：受け皿は左。左支点を外すと左へ流れ、反対を切ると受け皿を外す。切らずに残す意味を検証する配置。
- **共鳴の連鎖**：2つの足場、2つのコア。落下・衝突・共鳴の連鎖を狙う配置。

ステージは現時点では3つの導入・検証用配置です。長期的な難易度曲線、解法の多様性、繰り返し遊ぶ面白さは、今後のプレイテストで検証する必要があります。

## 開発

Node.js 22.12以降（本環境24.19）。

```sh
npm ci --cache /tmp/laser-npm-cache
npm run dev
npm test
npm run test:e2e
npm run build
node tests/pages-smoke.mjs
```

- `src/collapse.js`：物理世界、ステージ、支点、切断、面積管理、連鎖、成否。固定60Hz。
- `src/main.js`：入力、Canvas描画、UI、演出、音、記録。
- `src/geometry.js`：凸多角形分割、面積、重心。
- `tests/collapse.test.js`：放置時の支持、切断による崩壊、切る支点による結果差、コア連鎖、ショットと面積保存。
- Playwright：実操作でのクリア、誤った切断での失敗と再攻略、モバイル、キャンセル、設定、保存、周回。

旧版の色合わせ・ステージのルールとテストは比較用に残してありますが、現行ゲームでは使用していません。E2Eは `/usr/bin/chromium` を利用し、他環境で未導入なら `npx playwright install chromium` が必要です。

同じ固定ステップ入力で解法を確認していますが、実機Safari／Androidの描画性能や異なるMatter.js実行環境での完全一致、ゲームバランスは保証しません。広告・課金・外部分析はありません。設定で音と画面揺れ・粒子・振動を切替可能です。
